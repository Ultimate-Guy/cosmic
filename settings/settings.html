COSMIC

Settings

Customize Cosmic on this browser. Your choices are saved locally.

Appearance

Choose the colors and atmosphere used by Cosmic.

Background

Use a custom image and optionally enable the interactive background effect.

Images are stored locally in your browser and are limited to about 2.5 MB.

Custom Crosshair

Choose the on-screen crosshair style. Saved in this browser.

Interface

Control visual effects across Cosmic.

Background Music

Save music preferences and an optional uploaded MP3.

No audio file is bundled with Cosmic yet. Uploading an MP3 stores it in this browser for later use.

Tab Cloak

Choose the saved browser-tab appearance preference.

This stores the preference locally. Cosmic pages can use it when a cloak system is available.

Panic Shortcut

Choose a keyboard key and destination for a quick navigation shortcut.

The shortcut only navigates to the URL you choose. It does not hide or delete browser history.

Data

Remove Cosmic preferences stored in this browser.

This resets themes, background preferences, music preferences, and other Cosmic local settings. It does not delete your files.

About Cosmic

Local settings are stored with browser localStorage. No account is required.

Cosmic settings are designed to work on both GitHub Pages and Cloudflare by using browser-local preferences and relative site paths.
